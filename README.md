# Datasets-generated-with-Kijima-model-I
This folder contain 15 datasets, their sample size ranging from 20 to 300. Each dataset is generated with the model I from [1]: The time to the first failure is assumed to be the Weibull distribution with the shape parameter 2.0 and the scale parameter 20. The degree of the $k$th repair is generated from a random number with the uniform distribution U[0.8,1]. The file name suggests the sample size inside the file: for example, file name "Inter_Failure_Times_Kijima_I_300.xslx" suggests that there are 300 times between failures inside the file.

References

[1] Kijima, M., & Sumita, U. (1986). A useful generalization of renewal theory: counting processes governed by non-negative Markovian increments. Journal of Applied probability, 23(1), 71-88.
